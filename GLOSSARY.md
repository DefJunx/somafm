# Glossary

**Station**: A SomaFM radio channel (e.g. Groove Salad), shown as one tile in the grid.

**Grid**: The home screen listing every Station as an image tile.

**Tile**: One Station's card in the Grid; hovering it reveals a play control.

**Player screen**: The full-screen view for the currently selected Station, with transport and volume controls and the now-playing track.

**Active station**: The Station currently playing; it stays marked in the Grid while the user is back on it.

**Now playing**: The track currently broadcast on a Station.

**Favourite**: A Station the user has starred for quick access.

**Mirror**: One of a Station's interchangeable stream servers listed in its playlist; if one fails, another can be tried.
